## The label

> Captcha — a sacred test proving humans were human by making them identify traffic lights. Most humans failed.

One line (109 characters), written as the museum label a museum in the year 3000 puts beside a CAPTCHA — a deadpan misreading of an ordinary object from today, in the voice of a curator who has never seen one used.

## How it works

```sh
python3 main.py
```

Writes the label to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
